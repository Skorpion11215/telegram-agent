# TransferStats Agent (непрямая авторизация)

Прокси-агент для пересылки сообщений из Telegram-групп на сервер TransferStats
VectorLink Bot.

> Форк/переработка оригинального открытого модуля. Код полностью открыт,
> чтобы вы могли проверить, что агент делает только заявленное.

## Что делает агент

- Подключается к вашему Telegram-аккаунту через Telethon (сессия хранится только у вас).
- **bot-режим:** отправляет на сервер полный список ваших групп и получает
  обратно, какие из них транслировать (управление прямо в боте, по подписанному
  HMAC каналу обратной связи).
- **site-режим:** выбор групп на локальном сайте настройки (он же страница
  авторизации).

**Агент НЕ:**
- Отправляет сообщения в группы / читает личные сообщения.
- Не выполняет поиск, обработку или фильтрацию заказов — вся логика бота
  остаётся на сервере. Агент только пересылает текст и id.
- Не принимает произвольных команд с сервера: обратная связь = только набор
  id транслируемых групп, запроc синхронизации списка и ссылка перенастройки.

## Установка

### Ручная (терминал/SSH)

Подключитесь к вашему VPS (Termius или ssh) и выполните от root:

```bash
curl -sSL https://raw.githubusercontent.com/Skorpion11215/telegram-agent/HEAD/setup.sh \
  | bash -s -- <YOUR_TOKEN> --management bot --harden
```

- `<YOUR_TOKEN>` — выдаётся ботом: `/indirect_auth`
- `--management bot` — управлять группами из бота; `--management site` — через локальный сайт
- `--harden` — настройка безопасности сервера (ufw, fail2ban, обновления apt)
- `--endpoint URL` — адрес сервера (по умолчанию боевой)

После установки откройте ссылку локального сайта (бот придёт с нею в чат) —
там нужно только авторизовать Telegram; дальше все группы управляются из бота.

### Автоматическая (через бота)

В боте: `/indirect_auth` → «🤖 Управление в боте» или «🌐 На локальном сайте»
→ «⚡ Автоматически» → IP сервера, логин, пароль. Бот сам зайдёт на сервер,
выполнит установку с `--harden --non-interactive` и пришлёт ссылку авторизации.

Пароль используется только для разового SSH-подключения установкой, не
сохраняется и не логируется; после установки бот сгенерирует и пришлёт новый
пароль root.

## Управление

```bash
telegram-agent status       # Статус агента + режим управления
telegram-agent update       # Обновить код из репозитория и перезапустить
telegram-agent reconfigure  # site-режим: перенастройка групп
telegram-agent stop         # Остановить
telegram-agent start        # Запустить
journalctl -u telegram-agent -f   # Логи
```

## Безопасность

- Код полностью открыт.
- Все запросы подписаны HMAC-SHA256 (`api_key|timestamp|nonce|body`), анти-replay
  (nonce), ограничение частоты, чек-таймстемп.
- challenge-response проверка целостности агента от сервера (блокировка после 3
  провалов), binding к binary hash и hardware fingerprint.
- `agent.ini` с правами 600; при авто-установке — ufw + fail2ban + ротация пароля.
